# 모빌링손해사정 업무시스템 (기본 업무모듈)

React(Vite) + Supabase. 차량수리 손해사정 업무: 사고접수 → 배정 → 현장조사 → 견적검토 → 사정완료 → 보고서제출 → 종결.

## 실행
```bash
npm install
npm run dev      # 로컬 개발
npm run build    # dist/ 생성
```

Supabase 접속정보는 `src/lib.js`에 기본값으로 들어 있으며, 환경변수로 덮어쓸 수 있습니다.
```
VITE_SUPABASE_URL=https://wbqbkacwtzegzbcbegjj.supabase.co
VITE_SUPABASE_KEY=sb_publishable_...
```

## Vercel 배포
1. Vercel에서 새 프로젝트 생성 (Framework: Vite, Build: `npm run build`, Output: `dist`)
2. 이 폴더를 업로드하거나 Git 저장소로 연결
3. 배포 후 Supabase 대시보드 → Authentication → URL Configuration 에서 **Site URL** 을 배포 주소로 변경
   (가입 확인 메일 링크가 해당 주소로 돌아오도록)

## 첫 사용
- 처음 가입한 계정이 **관리자**가 됩니다. 이후 가입자는 손해사정사 권한으로 생성되며 [사용자 관리]에서 변경합니다.
- [보험사·정비공장]에서 거래 정비공장을 먼저 등록하면 접수·견적 입력이 편합니다. 보험사 8곳은 미리 등록되어 있습니다.

## 화면 구성
| 메뉴 | 기능 |
|---|---|
| 대시보드 | 진행/내 담당/미배정/기한초과 건수, 단계별 현황, 담당자별 건수, 7일 일정, 월 확정 인정액·삭감률 |
| 사건관리 | 검색(접수번호·사고번호·성명), 상태·종목·보험사·담당자 필터 |
| 사고접수 | 의뢰정보, 사고내용, 차량(복수) 동시 등록. 담당자 지정 시 '배정' 상태로 접수 |
| 사건 상세 | 기본정보 / 차량 / 견적검토 / 손해사정서 / 일정 / 처리이력 탭, 단계 진행 버튼 |
| 견적검토 | 차량별·차수별 견적서, 항목별 청구액·인정액·조정사유, 엑셀 붙여넣기, 구분별 합계·삭감률, 검토완료 처리 |
| 손해사정서 | 지급액 = (인정수리비 − 감가·공제) × 책임비율 − 자기부담금, 사정의견, 확정/해제, A4 출력(PDF 저장) |
| 일정 | 현장조사·입고/출고확인·면담 일정, 기간·내 일정 필터, 완료 체크 |

## 권한(RLS)
- 로그인 사용자만 접근. 조회·등록·수정은 전 직원 가능.
- 사건·보험사·정비공장·사정서 삭제는 관리자만. 차량·견적·견적항목·일정 삭제는 전 직원.
- 본인 권한(role)·사용여부 변경은 관리자만 가능 (DB 트리거로 차단).
